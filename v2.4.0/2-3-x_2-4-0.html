v2.4.0

    Migration guide from 2.3.x to 2.4.0

    Copy Markdown View Source

    MongoosePush now uses Sparrow 2 with Finch as its HTTP/2 client instead of Chatterbox.

    Prometheus metrics

    Update dashboards, recording rules, and alerts that use the removed sparrow_h2_worker_* or sparrow_pools_warden_* metrics, using the metrics guide as the reference. Review query semantics and alert thresholds rather than only replacing metric names; remove or redesign rules without an equivalent metric.

    API v3 error responses

    Update clients and tests to expect HTTP 503 instead of 500 for:

    • {"reason": "request_timeout"}
    • {"reason": "too_many_concurrent_requests"}

    Grafana dashboards

    Rebuild the bundled Grafana setup following the dashboard instructions. Restart Prometheus to apply the updated scrape configuration:

    docker compose -f test/docker/docker-compose.dashboard.yml restart prometheus

    For an external Grafana installation, import the updated dashboards using a version that supports the v2 dashboard format and row layouts; the bundled version is 13.3.0. The MongoosePush Metrics dashboard references datasource UID prometheus. Configure that UID or adjust the dashboard's datasource references to match your installation.

    For an external Prometheus installation, set Grafana's datasource scrape interval to the actual collection interval so that $__rate_interval is calculated correctly.
